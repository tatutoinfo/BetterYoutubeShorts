▶ YouTube Better Shorts

プライバシーポリシー

最終更新日：2026年9月28日

YouTube Better Shorts（以下「本拡張機能」）は、YouTube Shortsの操作性と情報表示を改善するために必要な情報だけを端末内で処理します。個人情報や閲覧履歴を収集せず、利用者のデータを開発者のサーバーへ送信しません。

1. 端末内に保存する情報

本拡張機能は、次の設定をブラウザのchrome.storage.localに保存します。

  • 再生速度、音量、ミュート状態
  • 自動送りの設定
  • 表示言語
  • 各機能の有効・無効
  • キー割り当て

これらの設定は利用者の端末内だけに保存され、開発者が受信または閲覧することはありません。

2. YouTube上で処理する情報

本拡張機能は、追加概要欄などの利用者向け機能を提供するため、現在および先に表示されるYouTube Shortsについて、YouTube上で公開されている次の情報を読み取ることがあります。

  • 動画ID、タイトル、説明
  • 高評価数、視聴回数、公開日
  • サムネイル

本拡張機能は、これらの情報をYouTubeのページ内で表示するためにのみ使用します。次の動画の情報をすばやく表示するため、YouTubeと同一オリジンのページおよび画像へ事前にアクセスする場合があります。一時的に読み取った動画情報はブラウザのメモリ内でのみ保持され、ページを閉じるか再読み込みすると消去されます。

3. 収集・送信しない情報

本拡張機能は、次の情報を収集、記録、販売または送信しません。

  • 氏名、住所、メールアドレスなどの個人を特定できる情報
  • 閲覧履歴
  • パスワード、認証情報、Cookie
  • 位置情報、健康情報、財務情報
  • 個人的なメッセージや通信内容
  • クリック、スクロール、キーストロークの履歴または分析データ

キー入力、クリック、スクロールは、割り当てられた操作をその場で実行するためにのみ検出され、記録や分析には使用されません。本拡張機能には、アクセス解析、広告、トラッキング機能はありません。

4. 第三者への共有

本拡張機能は、読み取ったページ情報や保存した設定を開発者または無関係な第三者へ送信せず、販売、貸与、広告利用もしません。機能提供に必要な通信は、HTTPSを使用したYouTubeとの同一オリジン通信に限定されます。

5. 権限の使用目的

  • storage：利用者が選択した拡張機能の設定を端末内に保存し、ページを再読み込みした後も維持するために使用します。
  • https://www.youtube.com/*：YouTube Shortsのプレーヤーを検出し、再生操作、設定UI、追加概要欄を提供するとともに、YouTube内のページ遷移に対応するために使用します。

6. リモートコード

本拡張機能はリモートコードを使用しません。実行するJavaScriptとCSSはすべて拡張機能のパッケージに含まれています。外部スクリプト、外部Wasm、eval()によるコード実行は行いません。

7. 保存期間と削除

端末内の設定は、利用者が設定をリセットするか、本拡張機能をアンインストールするまで保存されます。一時的な動画情報はページを閉じるか再読み込みすると消去されます。

8. Limited Useへの準拠

本拡張機能によるユーザーデータの使用は、Chrome Web Store User Data Policy（Limited Use要件を含む）に準拠します。取り扱う情報は、本拡張機能で明示した単一用途の提供にのみ使用します。

9. ポリシーの変更

機能やデータの取り扱いを変更した場合は、このページを更新し、最終更新日を変更します。重要な変更がある場合は、Chrome Web Storeの商品ページまたは本拡張機能内でお知らせします。

10. お問い合わせ

本ポリシーまたは本拡張機能についてのご質問は、tatutostudio@outlook.comまでお問い合わせください。

Privacy Policy

Last updated: September 28, 2026

YouTube Better Shorts (the “Extension”) processes only the information needed to improve playback controls and information display on YouTube Shorts. It does not collect personal information or browsing history, and it does not send user data to the developer's servers.

1. Information stored on your device

The Extension stores the following preferences in chrome.storage.local:

  • Playback speed, volume, and mute state
  • Automatic advance setting
  • Display language
  • Enabled or disabled state of each feature
  • Keyboard assignments

These preferences remain on the user's device. They are not received or viewed by the developer.

2. Information processed on YouTube

To provide user-facing features such as the additional details panel, the Extension may read the following publicly available information about the current and upcoming YouTube Shorts:

  • Video ID, title, and description
  • Like count, view count, and publication date
  • Thumbnail

This information is used only to display features within YouTube. To display information about upcoming videos quickly, the Extension may preload same-origin YouTube pages and images. Temporarily read video information is held only in browser memory and is removed when the page is closed or reloaded.

3. Information we do not collect or transmit

The Extension does not collect, record, sell, or transmit:

  • Personally identifiable information such as names, addresses, or email addresses
  • Browsing history
  • Passwords, authentication information, or cookies
  • Location, health, or financial information
  • Personal messages or communications
  • Histories or analytics of clicks, scrolling, or keystrokes

Key presses, clicks, and scrolling are detected only to perform the assigned action at that moment. They are not logged or analyzed. The Extension contains no analytics, advertising, or tracking features.

4. Sharing with third parties

The Extension does not send page information it reads or preferences it stores to the developer or unrelated third parties, and does not sell, rent, or use that information for advertising. Network requests required for its features are limited to secure HTTPS requests to same-origin YouTube resources.

5. How permissions are used

  • storage: Stores preferences selected by the user on the device and keeps them after the page is reloaded.
  • https://www.youtube.com/*: Detects the YouTube Shorts player, provides playback controls, settings UI, and an additional details panel, and supports navigation within YouTube.

6. Remote code

The Extension does not use remote code. All executable JavaScript and CSS are included in the extension package. It does not execute external scripts, external Wasm, or code through eval().

7. Retention and deletion

Local preferences remain until the user resets the settings or uninstalls the Extension. Temporary video information is removed when the page is closed or reloaded.

8. Limited Use compliance

The Extension's use of user data complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Information handled by the Extension is used only to provide its disclosed single purpose.

9. Changes to this policy

If the Extension's features or data practices change, this page and its “Last updated” date will be revised. Material changes will be announced on the Chrome Web Store listing or within the Extension.

10. Contact

For questions about this policy or the Extension, contact tatutostudio@outlook.com.
